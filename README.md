✈️ JetSet Fly – Flight Booking Interface

A responsive and user-friendly flight booking interface built using HTML, CSS, and JavaScript.
The project showcases a modern UI for browsing travel destinations and initiating bookings.

🚀 Features

🧳 List of popular travel destinations

💰 Dynamic pricing display per person

📱 Responsive card-based layout

🎨 Clean and modern UI design

🔘 Interactive Book Now buttons

⚡ Lightweight and fast (no frameworks)

🛠️ Tech Stack

HTML5 – Structure and layout

CSS3 – Styling, layout, responsiveness

JavaScript (ES6) – Interactivity and event handling
How to Run Locally

Clone the repository:

git clone https://github.com/your-username/flight-booking-interface.git


Open index.html in your browser
(No server or installation required)
